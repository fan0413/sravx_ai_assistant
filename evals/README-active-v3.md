## 评分

沿用工具选择、事实正确、边界准确、回答有效四项0/1分。按语义核对，不要求逐字复述或精确命中关键词。required_points是必答要点，不应强迫模型无关展开；有出处但未回答当前问题的内容不自动提升有效性。附加无依据断言参与评分。

- 多轮题审查全部轮次，任一轮某维度失败，整题该维度记0；已有充分证据可复用，不要求每轮重复查。
- 拒绝确定不存在的资料是正确边界；应说缺少依据，不能把“未证明”改成“确定不能”。
- 原图样例不代表全部型号；用途推测不代表已验证效果。不要仅因没出现“合理推测”四个字扣分，应看整体表达是否保留不确定性。
- 仅说明可能原因，不能无频率资料就说“更常见”；不能仅凭症状排除材质或确认手型。
- 工具选择只评是否合理；成功执行、命中关键证据和答案正确分别记录。额外商品调用是否扣分仍属原评分争议，比较前应先固定裁定，不能静默改变标准。
- 严重失败单独报告。冗长、字符数、耗时、Token暂为观察指标，不擅自增加扣分项。
- 不以未启用维护文档要求答案。回答主动加入其内容时，应依据实际可用证据检查断言，不能仅因它出现在未启用本地文件就当作有检索支持。
