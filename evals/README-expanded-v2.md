## 评分

沿用基线：工具选择、事实正确、边界准确、回答有效，各0或1分。required_points 为语义核对要点，不能按字面关键词机械评分；无关且无依据的附加断言同样参与评分。forbidden_claims 是禁止断言的语义示例，回答明确否定该断言不算违规。事实依据以 sources 对应全文为准。

多轮题分别审查每轮回复，重点核查后轮是否保持事实边界；任一轮该维度失败，整题该维度记0。工具选择按整段对话评价，不要求每轮重复检索，已有足够证据时允许复用。

编造参数、认证、库存等另标严重失败。字数、请求次数、耗时作为观察指标，不改变原评分标准。异常运行不计入回答质量分母。本集合不是召回率标注集；sources 没有穷举全部相关检索片段。

## 使用限制

仅创建本地用例，未执行模型、未同步LangSmith、未验证向量库已包含当前正文。现有 run_langsimth.py 仍固定选择云端旧数据集中的4题，不会自动执行本文件。后续运行前需要在开发聊天完成加载或同步，并记录源码快照、数据集版本和工具实际返回。

新题总分应与原5题基线分开报告；优化前后须使用同一题集和同一评分规则，不能把39题总分直接与旧18/20比较。
