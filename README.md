# SRAVX 用户端商品推荐助手

状态：立项准备，尚未初始化模型或实现工具。GitHub 名称与公开性待确定。

面向宠物美容师，通过真实商品查询回答选购问题，最终接入现有商城的用户端。

## 第一阶段范围

- 根据关键词、系列、剪型查询在售商品。
- 读取候选商品详情，核实规格和价格后给出推荐依据。
- 无匹配或资料缺失时明确说明，不编造商品、参数、库存或用途。
- 不执行下单、改价、退款、发布或优惠承诺。

## 开发顺序

1. 确定模型服务商、模型名称与调用预算，核实原生工具调用支持。
2. 创建本地配置与最小模型调用示例，验证普通文本响应。
3. 使用模拟数据实现 searchProducts，再核对真实只读接口。
4. 实现工具调用循环、参数校验、超时、调用次数限制与错误处理。
5. 完成推荐验收，再在原商城开发分支接入用户页面。

当前未安装依赖、未创建模型账号、未产生模型调用费用。
