## 内容维护说明

- 每个知识章节尽量围绕一个问题，明确品牌、对象及资料性质。
- 商品名称使用China 440C，材料属性按9CR18说明，品牌性能评级参照440C。
- 材料数据、品牌内部评级与成品实测数据分别记录；资料缺失时标明状态。
- 价格、库存及在售规格属于实时商品信息，本目录不保存推测值。
- 推荐流程、默认条件、追问次数等属于助手行为规则，不作为专业知识正文维护。已有规则保存在知识目录外的[维护保留记录](../docs/knowledge-maintenance.md)，本次未修改应用提示词。

## 后续导入建议

以下为导入维护说明，不是已经实现的检索能力。

- 导入范围明确选择知识正文文件，排除本README和知识目录外的维护记录。
- 优先按标题拆分；资料卡保持品牌、名称、属性、评级性质和来源在同一片段内。
- 钢材对比表保持表头与评级性质说明关联；如表格过长，优先检索独立钢材资料卡。
- 每段附带文档路径、完整标题层级、品牌、更新时间和资料类型，来源链接随相关片段保留。
- 编辑Markdown不等于数据库自动更新；重新入库时需替换旧版本，避免新旧内容同时命中。
